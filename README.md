# Amirhossein Naseh Poshteri — Portfolio

Bilingual (English / فارسی) personal portfolio & resume site — a single `index.html` with pure HTML/CSS/JS, no build step.

## ✨ Features

- Light modern theme with indigo → cyan gradient accents
- English (default) / Persian with full RTL switch — preference persisted in `localStorage`
- Hero with animated typing roles and a C# code card
- Sections: About, Skills, ERP work experience at Parsan, featured GitHub projects, education & certifications, contact
- One-page ATS-friendly resume PDF: [`Amirhossein-NasehPoshteri-Resume.pdf`](Amirhossein-NasehPoshteri-Resume.pdf)
- Fully responsive — desktop, tablet and phone

## 🌐 Live site

GitHub Pages: <https://zomirex.github.io/portfolio/>
